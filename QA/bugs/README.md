# QA/bugs — criterio de esta carpeta

Un archivo entra aquí **solo** cuando un caso de `QA/to-prove.md` se ejecutó de verdad (en vivo, contra la app real o `harness.html`, con evidencia concreta) y algo se rompió. Mismo criterio de honestidad que el resto del proyecto (`docs/reference/inventario-funcionalidades-qa.md`): sin ejecución literal, no hay bug, hay como mucho una sospecha — y una sospecha va a `QA/OPmejora/`, no aquí.

Plantilla: sección 4 de `QA/to-prove.md`. Un archivo por bug, nombre `<slug-corto>.md`.

No hay archivos todavía — a la fecha de este README (2026-09-12), el trabajo hecho sobre esta carpeta fue lectura estática de código (grep/Read), no ejecución. Ver `QA/OPmejora/` para lo que salió de esa lectura.

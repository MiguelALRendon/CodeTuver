> `CLAUDE.md` lo referencia como "Mapa del sistema". Principios de producto en `docs/constitution.md`.

## Fronteras no negociables

Estas fronteras están fijadas, no son preferencia de implementación — ningún plan de Epic las reabre:

- **El motor de reacciones y el avatar están separados.** "El motor emite intenciones; el avatar decide cómo representarlas según lo que su formato permita." El motor no consulta el modo de presentación ni el personaje activo; si una reacción no es compatible con el avatar cargado, la capa de avatar aplica su propio fallback declarado.
- **La ventana no conoce la lógica de sesión.** El `PresentationManager`/`DesktopWindowManager` recibe estado y eventos por interfaces públicas; nunca habla directamente con el proceso de Claude Code ni con detalles internos del transporte (ADR-0004).
- **La presentación no sabe que es escritorio.** El acceso nativo vive aislado tras una capa delgada sobre `invoke`/eventos de Tauri; los componentes Vue no llaman a Tauri directamente (ADR-0002).
